# 🚀 NovenoProyecto

Proyecto Node.js con arquitectura MVC (Model - View - Controller).

---

# 📌 Crear el proyecto desde cero

## 📁 Crear carpeta del proyecto

```bash
mkdir NovenoProyecto
cd NovenoProyecto
```

## 📦 Inicializar Node.js

```bash
npm init -y
```

---

# ⚙️ Instalación de dependencias

```bash
npm install express
```

(opcional si usas nodemon)

```bash
npm install nodemon --save-dev
```

---

# 📂 Estructura del proyecto

```bash
src/

── controllers/
── models/
── views/
```

Archivo principal:

```bash
app.js
```

---

# ▶️ Ejecutar el proyecto

## Modo normal

```bash
node app.js
```

## Modo desarrollo (si usas nodemon)

```bash
npm run dev
```
